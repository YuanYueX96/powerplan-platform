# v1.0 · 首个公开版本（Release Notes）

> 发布日期：2026-11-06
> 下载：`platform-source-v1.0.zip`（本页 Assets）

## 这是什么

基于市场环境的电力系统规划仿真平台 · 模块一（电力系统规划）v1.0。

把「源网荷储规划模型」从 CSV 规范与求解脚本，做成可视化、可复现、可交付的
五步闭环工具：**建模 → 运行边界 → 算法参数 → 执行计算 → 结果分析**，外加多方案对比。

## 亮点

- **算法零侵入**：平台与求解核心通过五个函数的接口契约解耦（`load_case / validate /
  SGLSModel / write_all / verify`），算法包一行未改，可替换实现。
- **求解规模可预判**：Gurobi 受限许可（≤2000 变量）下，按
  `T × (机组×3 + 节点 + 线路 + 2)` 实时预估规模，计算周期支持 24h / 168h / 720h / 全年切片。
- **结果可信**：独立校验器从输出 CSV 反算 M1~M5，PASS / FAIL 与明细直达结果页。
- **部署最简**：无构建链、无外部数据库，单进程 + SQLite，`start.bat` 一键启动，
  内网 / 离线机器可用（图表库随包内置）。
- **空状态即真空**：无数据不画图、不造 KPI，清单由用户自建。

## 已知限制

- 本仓库**不含求解算法实现**（版权保留，见 `algorithm/README.md` 接口契约）；
  建模 / 边界 / 参数 / 对比功能克隆即可用，求解需接入自己的实现。
- Gurobi 受限许可仅支持 24~720 时段算例；全年 8760h 需完整许可（学术 WLS 免费申请）。
- 平台无账号体系，仅建议内网使用。

```bash
./start.sh          # 默认 8000 端口
```
